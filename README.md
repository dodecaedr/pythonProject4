## Примеры использования:

**Фильтрация данных по состоянию:**

from processing import filter_by_state

transactions = [
    {'id': 1, 'state': 'EXECUTED', 'date': '2023-01-01T12:00:00'},
    {'id': 2, 'state': 'CANCELLED', 'date': '2023-01-02T13:00:00'},
    {'id': 3, 'state': 'EXECUTED', 'date': '2023-01-03T14:00:00'}
]

filtered_transactions = filter_by_state(transactions)
print(filtered_transactions)

**Результат:**

[{'id': 1, 'state': 'EXECUTED', 'date': '2023-01-01T12:00:00'},
 {'id': 3, 'state': 'EXECUTED', 'date': '2023-01-03T14:00:00'}]

**Сортировка данных по дате:**

from processing import sort_by_date

transactions = [
    {'id': 1, 'state': 'EXECUTED', 'date': '2023-01-01T12:00:00'},
    {'id': 2, 'state': 'EXECUTED', 'date': '2023-01-03T14:00:00'},
    {'id': 3, 'state': 'EXECUTED', 'date': '2023-01-02T13:00:00'}
]

sorted_transactions = sort_by_date(transactions)
print(sorted_transactions)

**Результат:**

[{'id': 2, 'state': 'EXECUTED', 'date': '2023-01-03T14:00:00'},
 {'id': 3, 'state': 'EXECUTED', 'date': '2023-01-02T13:00:00'},
 {'id': 1, 'state': 'EXECUTED', 'date': '2023-01-01T12:00:00'}]

## Основные концепции и принципы работы:

**filter_by_state():** Перебирает каждый словарь в списке и добавляет его в результат, если значение поля state совпадает с заданным.

**sort_by_date():** Использует встроенную функцию sorted() с ключом сортировки по дате, переведенной в объект datetime.

## Реализация и тестирование функций обработки транзакций:
Реализованы три ключевые функции для работы с банковскими транзакциями и номерами карт:
- **filter_by_currency**

Фильтрует список транзакций по указанной валюте (поле operationAmount.currency.code).
Вход: список транзакций, код валюты (например, "USD").
Выход: итератор отфильтрованных транзакций.

- **transaction_descriptions**

Возвращает описания операций из списка транзакций.
Вход: список транзакций.
Выход: итератор строк (None, если поле отсутствует).

- **card_number_generator**

Генерирует форматированные номера банковских карт (16 цифр, разбитые на группы по 4 через пробел).
Вход: диапазон чисел (start…end).
Выход: итератор строк вида "XXXX XXXX XXXX XXXX".
